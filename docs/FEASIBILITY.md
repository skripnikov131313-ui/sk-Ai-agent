# Реализуемость автономного агента

Дата: 2026-11-13.

## Рекомендованный режим

Codex Cloud запускает кодовые задачи на управляемой OpenAI машине и поддерживает продолжение с desktop/web/mobile, в том числе когда локальный компьютер спит. Среда с обоими репозиториями опубликована пользователем, текущая машина проверена 2026-11-14. Кодовые изменения нужно регулярно сохранять в Git; отдельные задачи не подхватывают автоматически незакоммиченные файлы другой задачи. Это не гарантирует бесконечную фоновую работу: приостановка среды уже наблюдалась, её точная причина неизвестна. Продолжение с телефона и конкретные квоты ещё не испытаны.

## Обычная подписка и API

Доступ к Codex в ChatGPT плане и биллинг OpenAI API — разные вещи. Cloud доступ зависит от плана/rollout; текущая диагностика показывала Plus, не исчерпанный лимит Codex и отсутствие отдельных API credits. Не строить облачный сервис, опираясь на пользовательский Plus как на общий API ключ.

## Локальная ошибка запуска

В терминале пользователя `node` не найден в PATH. Этот Codex Desktop установил Node только внутри каталога `WindowsApps\OpenAI.CodexPrimaryRuntime...\dependencies\node\bin`. `agent.cmd` ищет в этом пакете или в PATH, не устанавливает Node и не требует admin прав.

Отдельный blocker: вложенный `codex exec` запустился, но сообщил, что локальная команда не может быть запущена (`registered Core launch requires an installed app`). Smoke task поэтому имеет результат `blocked`; нельзя считать executor готовым.

## Подтверждённый Windows запуск — 2026-11-15

Для текущей установки через WinGet native Codex CLI `0.168.0` успешно найден по полному package-пути и использует существующий ChatGPT login. На Node.js `26.13.1` пользователь запустил актуальный Agent из ветки `cloud/agent-reliability`; его `smoke` вернул PASS / completed с независимой проверкой созданного файла. Идентификатор задачи: `0b7edf0d-5920-4d51-8a17-f4f0c80b6567`.

Ранний Desktop/Core запуск выше остаётся исторической неудачной попыткой. Текущий маршрут WinGet/native CLI подтвердил положительную файловую операцию. Реальное interrupt/resume, отрицательная проверка sandbox, мобильное продолжение и доступные квоты требуют отдельных результатов.
