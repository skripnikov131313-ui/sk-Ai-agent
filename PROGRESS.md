## Windows bootstrap — диагностика Node.js

- На Windows пользователя установлен Git и склонирована рабочая ветка. `agent.cmd doctor/list` остановились до запуска CLI: Node.js не найден прежним launcher.
- Подтверждено по коду: старый поиск охватывал PATH и только `OpenAI.CodexPrimaryRuntime.*`, пропуская обычные Node-папки и MSIX с `_` перед версией. Наличие Node на ПК пользователя этим не установлено.
- Поиск расширен стандартными папками и MSIX-шаблоном, добавлен явный `SKAI_NODE_EXE`. Несуществующий override и runtime старше допустимого диапазона не маскируются fallback. Требуется Node.js 24+.

- При первом CI эти проверки обнаружили проблемы в обработке bootstrap-ошибок и изоляции fixture-папок: cmd в CI использовал системный ProgramFiles вместо переданного через env.
