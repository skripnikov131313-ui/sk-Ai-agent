# Инструкции

- Используй официальный Codex как исполнитель и Cloud как основной удалённый маршрут; не храни API ключ OpenAI в этом проекте.
- Локальные команды ограничивать корнем проекта, временем, лимитом повторов и явным отчётом.
- Не использовать режимы обхода approvals/sandbox и не пытаться получать административные права.
- Не выполнять системные установки, публикации, удаление вне репозитория или расходы без подтверждения.
- Сохраняй устойчивые состояния задач, логи без секретов и понятную причину блокировки.
- В явно выбранном режиме `work` продолжай независимые пункты конечного плана без запроса «дальше»; соблюдай общий бюджет и лимит попыток. Новые пункты и снятие блокировок не должны бесконечно продлевать запуск. Отсутствие отчёта или исчерпание бюджета — причина остановки.
- Для задач, требующих Windows/GUI, указывать локальный режим и ждать доступности компьютера; не открывать PowerShell/RDP в интернет.
- Учитывать, что Codex Plus не является API-кредитом произвольного поставщика.
