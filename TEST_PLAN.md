# Проверки

## Выполняются локально

- четыре unit-теста проверяют хранилище, валидацию цели и обработку отчёта.
- smoke test проверяет CLI/login, структуру событий и корректный `blocked`, если nested local tool недоступен.
- запуск через `agent.cmd list` должен работать даже если `node` не в PATH.

## Ещё проверить

- sandbox не записывает файлы выше каталога репозитория.
- аварийное прекращение убивает весь процесс Codex CLI.
- возобновление сохраняет и применяет thread ID.
- Cloud environment реально создаёт задачу, запускает тесты и позволяет продолжение с телефона после публикации.
