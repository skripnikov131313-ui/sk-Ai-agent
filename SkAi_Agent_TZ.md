# Sk/Ai Agent — техническое задание
Версия 1.2, 12.11.2026. Статус: спецификация для реализации и проверки возможностей Codex.

## Главная цель
Максимально автономный универсальный агент для разработки Sk/Ai Browser и иных проектов. Пользователь формулирует результат в чате; агент самостоятельно планирует, выполняет разрешённые действия, проверяет, исправляет ошибки и сообщает результат. Оценка — по проверенным выполненным задачам, а не по инструкциям.

## Среда
Windows 11 x64, Ryzen 5, 12 ГБ RAM, SSD; не перегружать локальный компьютер. Облако по умолчанию для подходящих задач; Windows для локальной интеграции/GUI. Возможность отправлять задания с iPhone, включая время, когда ноутбук выключен, если облачная инфраструктура доступна.

## Компоненты
1. Bootstrap Agent — временный настройщик.
2. Core Agent — постоянный исполнитель на основе Codex и доступных инструментов.
3. Task Orchestrator — собственный диспетчер задач и сред.
4. Agent Chat — единый интерфейс задач, статусов, подтверждений, логов и результатов.
5. Memory & Learning — долговременный проектный контекст и улучшение методов.

## Обязательная автономная установка
Bootstrap Agent сначала САМ выполняет все технически возможные и разрешённые действия: аудит Windows, настройка Git, Codex CLI, рабочих каталогов, CI, проверка инструментов, тестовые запуски. Не ограничиваться генерацией инструкций. Если требуется участие человека, указать точное окно, кнопку, ожидаемый результат; не просить пароли и коды в чате. Системные установки, админ-права, секреты и потенциально разрушительные операции — только с подтверждением. Вести журнал и точки отката. После испытаний отключить временного настройщика и отозвать его временные права.

## Исполнение задач
План → выбор среды → выполнение → тест → исправление → фиксация результата → следующий этап. Ограничения повторов, времени, бюджета и ресурсов; остановка и запрос решения при блокере. Очередь задач, сохранение контрольных точек, безопасное возобновление после сбоев. Не обещать бесконечную работу без ограничений сервисов.

## Гибридная маршрутизация
Облачный Codex и CI для кода/сборок; локальный Codex для Windows API, файлов, запуска GUI и проверок. Автоматическая маршрутизация и обмен результатами требуют собственной реализации и проверки доступных API/интерфейсов. Если ноутбук выключен, локальные задачи ожидают включения, облачные могут продолжаться. Не предполагать единую память или автоматическую синхронизацию Codex и ChatGPT.

## Инструменты
PowerShell, Git/GitHub, GitHub Actions (Windows runner), компиляторы, тесты, Playwright для браузерных проверок, GUI-автоматизация при необходимости. Применять минимальные права, изолировать рабочие каталоги, не открывать RDP/PowerShell напрямую в интернет. Не хранить токены в коде. Проверять лимиты Plus и отдельные API-расходы до интеграции.

## Долговременная память
В каждом репозитории: AGENTS.md, PROJECT.md, REQUIREMENTS.md, ARCHITECTURE.md, TASKS.md, DECISIONS.md, PROGRESS.md. Обновлять после этапов, хранить историю решений, ссылки на коммиты, результаты тестов и известные ошибки. Восстанавливать контекст из файлов, а не полагаться на память чата.

## Самообучение и улучшение
Обязательный модуль Self-Learning & Continuous Improvement:
- фиксировать ошибку, контекст, проверенное исправление и результат;
- извлекать повторно используемые инструкции и скрипты;
- учитывать обратную связь пользователя;
- проверять улучшения тестами и метриками;
- откатывать ухудшения;
- не переписывать правила безопасности, не расширять собственные разрешения и не устанавливать неподтверждённые инструменты самостоятельно.
Это обучение на опыте/памяти, а не изменение весов моделей OpenAI или гарантированное повышение интеллекта.

## Контроль безопасности
В рабочей области: редактирование кода, тесты, локальные коммиты — автоматические в пределах разрешений. Установка системного ПО, публикация, удаление вне проекта, передача секретов, расходы, изменения политик — явное подтверждение. Аварийная остановка, журнал, резервные копии при риске потери данных. Запрет обхода UAC/защиты Windows.

## Этапы
Аудит → Bootstrap → локальный исполнитель → облачный исполнитель → диспетчер → чат/iPhone → тесты отказоустойчивости и безопасности → отключение Bootstrap → передача Sk/Ai Browser основному агенту.

## Критерии приёмки
Задача из чата проходит планирование и проверенное исполнение; GitHub хранит код и историю; CI выдаёт проверяемые артефакты; локальные действия исполняются только при доступном Windows; прерванная задача восстанавливается; опасные действия требуют подтверждения; пользователь видит прогресс и результат; Bootstrap можно отключить без потери работоспособности.

## Первое поручение Codex
Сначала проверь доступные возможности Codex, подписки и окружения. Составь план и риски. Затем самостоятельно выполни разрешённую настройку, а не только напиши руководство. Реализуй минимально работоспособную систему, протестируй каждый компонент, документируй ограничения. После успешной приёмки начни проект Sk/Ai Browser по отдельному ТЗ.
