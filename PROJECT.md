# Sk/Ai Agent

## Цель

Помогать разрабатывать и сопровождать Sk/Ai Browser и другие проекты через Codex. Облачные задачи выполнять на подготовленном Codex Cloud, чтобы продолжать с мобильного и когда ноутбук выключен. Windows-специфичные действия оставлять локальному ограниченному worker.

## Границы

- Agent — система разработки, Browser — отдельный пользовательский продукт.
- Agent не требует своего LLM, если Codex Cloud решает задачу без дополнительной API-интеграции.
- Локальная очередь — вспомогательный MVP, не сервис для круглосуточной работы.
- Внешняя публикация, системные установки, расширение разрешений и расходы требуют явного согласования.
