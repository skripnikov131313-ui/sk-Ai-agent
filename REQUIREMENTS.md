# Требования

- Пользователь может ставить облачные задачи с поддерживаемого desktop/web/mobile-клиента.
- Cloud task может работать, пока локальный компьютер выключен.
- Windows-specific задача сохраняет очередь до включения локальной машины.
- Идентификаторы, состояние, дедлайн, попытки и отчёт сохраняются; задача не помечается готовой только на основе exit code.
- Компонент работает с минимальными правами и не передаёт секреты в prompt или логи.
- Репозитории Agent и Browser изолированы.
- Текущий локальный CLI — MVP, не готовая мобильная/облачная система.
